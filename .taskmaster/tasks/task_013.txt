# Details:
Implemented three complex chart generators with full TypeScript support, theme compatibility, and extensive testing:

1. Voronoi Chart Generator:
- Supports 7 shape types
- Auto/fixed drawing modes
- Configurable corner radius and opacity
- Automatic color schemes

2. Sankey Chart Generator:
- Configurable node width and gap distance
- Line opacity control
- Multiple color modes (auto, gradient, custom)
- Automatic color scheme generation

3. Treemap Chart Generator:
- Configurable gap distance
- Border and opacity settings
- Corner radius support
- Automatic color schemes
